# TICKET-207: 대칭 경계, 두 개의 valuation-1 주기, 로그 증인, Abel 누출

## 주장 상태

네 상위 추측은 모두 `open_not_proven`, 즉 **미해결**이다. TICKET-207은
정확한 부분정리 또는 no-go 정리 네 개를 증명한다. 리만 가설, 콜라츠
추측, 강한 골드바흐 추측, 쌍둥이 소수 추측 가운데 어느 것도 증명하거나
반증하지 않았다.

표준 기계 판독 산출물은

## 1. 리만 가설

### 이번에 증명한 정확한 명제

완성 리만 제타 함수, 즉 해석하기 편하도록 감마 함수 등을 결합한 함수

```text
xi(s) = (1/2)s(s-1) pi^(-s/2) Gamma(s/2) zeta(s)
```

를 생각하자. 실수축과 `Re(s)=1/2` 직선에 대해 대칭인 직사각형 `R`에서

```text
xi(s)=xi(1-s),
xi(conjugate(s))=conjugate(xi(s))
```

가 성립한다. 여기서 `conjugate`는 복소켤레이다. 이 두 등식으로 전체
경계의 함수값, `|xi|`의 경계 최솟값, `|xi'|`의 경계 최댓값을 다음 두
부분만으로 정확히 결정할 수 있다.

1. 위쪽 변 전체
2. 오른쪽 변의 위쪽 절반

따라서 TICKET-206의 winding, 즉 원점 주위를 몇 번 감는지 인증하는 구간
계산은 이 기본 경계 영역에서만 수행하면 된다.

### 증명

복소켤레는 위쪽 변을 아래쪽 변으로, 오른쪽 위 절반을 오른쪽 아래
절반으로 보낸다. 반사 `s -> 1-s`는 왼쪽 변을 오른쪽 변으로 보낸다.
함수 방정식을 미분하면

```text
xi'(s)=-xi'(1-s)
```

이므로 미분값의 절댓값도 똑같이 축소된다. 이 변환들은 전체 경계를
위의 기본 영역의 상들로 덮고 절댓값을 보존한다. 따라서 전체 경계와
기본 영역에서 clearance, 즉 원점으로부터의 최소 거리와 미분 상계가
정확히 같다.

### 대칭만 사용하는 경로의 no-go

`0<c<1/2`일 때

```text
F_c(s)=(s-1/2)^2-c^2
```

는 전체 복소평면에서 해석적인 함수이며 `xi`와 같은 반사·켤레 대칭을
가진다. 하지만 영점은 `1/2-c`, `1/2+c`로 둘 다 임계선
`Re(s)=1/2` 밖에 있다. 정확 계산에서는 `c=1/3`, 영점 `1/6`, `5/6`을
사용했다.

이 함수는 `xi`가 아니므로 리만 가설의 반례가 아니다. 정확한 결론은
“반사와 켤레 대칭만으로 모든 영점이 임계선에 있다고 증명할 수 없다”는
것이다. 제타 함수에만 존재하는 추가 해석적 정보가 필요하다.

### 남은 간극

무한히 커지는 직사각형 계열의 축소 경계에서 `|xi|>0`인 엄밀한 구간
하한을 아직 만들지 못했다. 원하는 무영점 결론을 전제로 쓰지 않고 이
하한을 구성하는 것이 다음 핵심 보조정리다.

## 2. 콜라츠 추측

### 이번에 증명한 정확한 명제

홀수만 남기는 가속 콜라츠 사상

```text
T(x)=(3x+1)/2^v2(3x+1)
```

에서 valuation, 즉 `3x+1`을 나누는 2의 최대 지수가 `1`인 단계가 정확히
두 개이고 나머지 valuation이 모두 임의의 `>=2`인 비자명 양의 주기는
없다. TICKET-206과 결합하면 가상의 비자명 양의 주기는 valuation-1
단계를 적어도 세 개 가져야 한다.

### 긴 주기의 증명

길이 `h`인 가상 주기를 가장 작은 홀수 `m`부터 시작하도록 회전시킨다.
첫 valuation은 반드시 `1`이다. `2` 이상이면 다음 값이 `m`보다 작아져
최솟값 정의와 모순이다. 다음 두 함수를 둔다.

```text
G(x)=(3x+1)/2,
F(x)=(3x+1)/4.
```

두 valuation-1 단계 사이의 수축 단계를 `r`, 두 번째 이후의 수축 단계를
`s`라 하면 `r+s=h-2`이다. 두 번째 valuation-1이 마지막 전이일 수는
없다. 그 직전 값이 `x>=m`인데 `G(x)>x`이므로 `m`으로 돌아올 수 없기
때문이다. 따라서 `s>=1`이다.

valuation이 2 이상인 실제 단계는 항상 `F`보다 작거나 같다. 다음을 두면

```text
q=(3/4)^(h-2),
q_s=(3/4)^s,
```

단조성과 주기 귀환으로

```text
m <= F^s G F^r G(m)
  = 1+q_s-3q/4+(9q/4)m
```

을 얻는다. `h>=5`에서는 `q_s<=3/4`이므로

```text
m <= (7/4-3q/4)/(1-9q/4).
```

오른쪽은 `q`에 대해 증가한다. 정확한 상계와 남은 후보는 다음과 같다.

| 길이 | `m`의 상계 | 남은 정확 후보 |
|---|---:|---|
| `h>=8` | `m<=26485/9823<3` | 없음 |
| `h=7` | `m<=6439/1909<4` | `m=3` |
| `h=6` | `m<=1549/295<6` | `m=3,5` |
| `h=5` | `m<=367/13<29` | `3`부터 `27`까지의 홀수 |

마지막 세 행의 모든 후보는 정수 가속 사상을 그대로 재생하여 귀환하지
않음을 확인했다. 이 계산은 상계로 후보 집합을 유한하게 만든 뒤 전부
확인했기 때문에 해당 세 경우에 대해서는 완전하다.

### 짧은 주기의 증명

`h=4`에서 두 번째 `1`은 두 번째 또는 세 번째 위치에 있다. 정확한 주기
식은

```text
(1,1,b,c): m=(57+2^(b+2))/(2^(b+c+2)-81),
(1,b,1,c): m=(45+10*2^b)/(2^(b+c+2)-81)
```

이다. `b,c>=2`, 양의 분모, `m>=3`을 적용하면 각각

```text
(3*2^c-1)2^(b+2)<=300,
(12*2^c-10)2^b<=288
```

를 얻는다. 두 부등식 모두 `b=c=2`만 남기지만 이때 분모는
`64-81<0`이다. `h=3`의 유일한 형태 `(1,1,b)`는

```text
m=19/(2^(b+2)-27)
```

이고 양의 `m>=3` 후보 `b=3`은 `m=19/5`라서 정수가 아니다. `h=2`의
`(1,1)`은 분모 `4-9<0`이다. 모든 길이가 배제되었다.

### 남은 간극

이 정리는 하나의 주기 층 전체를 닫았을 뿐 콜라츠 추측을 해결하지
않았다. valuation-1이 세 개 이상인 주기와 주기 없이 무한히 커지는 궤도
가능성은 남아 있다.

## 3. 강한 골드바흐 추측

### 이번에 증명한 정확한 명제

`W(N)`을 `N-p`도 소수가 되는 가장 작은 소수 `p`라 하고, 표현이 없으면
`W(N)=infinity`라 하자. 무한히 커지는 짝수 `N`의 수열 중

```text
W(N) > (1/3) log N
```

을 만족하는 수열이 존재한다. 따라서 `b(N)=o(log N)`, 즉 로그보다
점근적으로 작은 cutoff는 모든 짝수를 덮는 보편적 골드바흐 증인 집합이
될 수 없다.

### 증명

충분히 큰 `B`마다 소수정리는 구간 `(B,3B)`에 적어도 `pi(B)-1`개의
소수가 있음을 준다. 각 홀수 소수 `p<=B`에 서로 다른 `q_p`를 배정한다.
중국인의 나머지 정리, 즉 서로소 합동식을 동시에 푸는 CRT로

```text
N=0 (mod 2),
N=p (mod q_p), 모든 홀수 소수 p<=B
```

를 만족하는 수를 만든다. 다음을 두고

```text
M=2 product_(3<=p<=B) q_p
```

`M<N<2M`인 대표를 고른다. 큰 `B`에서 `N-p`는 `q_p`의 진정한 배수라
합성수이고, `N-2`도 2보다 큰 짝수라 합성수이다. 따라서 `W(N)>B`이다.

모든 `q_p<3B`이고 소수정리를 다시 쓰면 충분히 큰 `B`에서

```text
log M <= log 2+(pi(B)-1)log(3B) <= 2B
```

이다. 그러므로 `log N<log(2M)<3B`이고
`W(N)>B>(1/3)log N`이다. `M`은 무한히 커지므로 원하는 수열을 얻는다.
기계 검증 예제는 실수 로그 대신 정확한 정수 조건
`bit_length(N)<=3B`를 확인한다. `log N<bit_length(N)`이므로 같은 결론을
부동소수점 오차 없이 인증한다.

### 논리적 한계

이 결과는 골드바흐 반례가 아니다. `p<=B`만 막았고 더 큰 소수는 여전히
`N`을 표현할 수 있다. 이 정리는 앞으로의 증인 꼬리 분석이 넘어야 할
최소 규모를 정했다. 예외 개수가 1 미만이라는 필요한 상계는 아직 없다.

## 4. 쌍둥이 소수 추측

### 이번에 증명한 정확한 명제

`0<r<1`, `m>=1`에 대해 정규화한 Abel projector를

```text
Q_r(m)=r^(-1) sum_(j=1)^m (-1)^(j-1) j binom(m,j) r^j
```

로 두면

```text
Q_r(m)=m(1-r)^(m-1)
```

이다. 따라서 `Q_r(1)=1`이지만 합성수에 해당하는 모든 `m>=2`에서도
`Q_r(m)>0`이다. 고정된 `r`은 `m=Omega(n)`, 즉 소인수 중복 개수를
대입해도 정확한 소수 판별기가 아니다.

각 정수 `X>=1`에 대해 `r_X=1-1/(16X)`로 두고

```text
S_X = sum_(X<n<=2X) Q_rX(Omega(n)) Q_rX(Omega(n+2))
```

를 정의하자. 같은 구간에서 쌍둥이 소수의 작은 쪽 개수를 `T_X`라 하면

```text
T_X <= S_X <= T_X+1/8,
floor(S_X)=T_X
```

가 정확히 성립한다. `floor`는 소수점 아래를 버리는 바닥 함수이다.

### 증명

`(1-r)^m`을 미분하면 닫힌식을 얻는다. `r_X`에서는 합성수의 모든
중복 소인수 개수 `m>=2`에 대해

```text
Q_rX(m)=m/(16X)^(m-1) <= 1/(8X)
```

이고 소수의 가중치는 1이다. 쌍둥이 소수 항은 정확히 1을 더한다.
쌍둥이가 아닌 항에는 합성수 끝점이 적어도 하나 있고, 항은 음이 아니며
`1/(8X)` 이하이다. 작은 쪽 후보가 정확히 `X`개이므로 전체 누출은
`1/8` 이하이고 바닥 함수를 취하면 `T_X`를 정확히 복원한다.

### 양성 순환성 no-go

이 식은 모든 끝점의 `Omega(n)`를 실제 계산하기 때문에 유한 쌍둥이
개수를 정확히 다시 표현한다. 새로운 하한은 아니다. 충분히 큰 모든
`X`에서 `S_X>0`임을 쌍둥이 개수 자체와 독립적인 부호 있는 산술 주항으로
증명해야 실제 진전이 된다. 음이 아닌 Abel 누출만으로는 쌍둥이 소수의
기여와 합성수 누출을 구분할 수 없다.
