## 1. 리만 가설

### 이번에 증명한 정확한 명제

충분히 큰 모든 정수 `n`에 대해 `T_n in (n,n+1)`을 골라

```text
-1/4 <= Re(s) <= 5/4, Im(s)=T_n
```

인 중앙 수평선에서 `zeta(s)`가 영이 아니게 할 수 있습니다. 이 닫힌 구간의
절댓값 최솟값도 양수입니다. 그러나 이 존재 명제만으로 RH는 따라오지
않습니다.

`z=s-1/2`로 두고

```text
P(s)=z^4+(15/8)z^2+289/256
```

로 두면 `P(1-s)=P(s)`라는 함수방정식형 대칭과 복소켤레 대칭을 모두
만족합니다. 그런데 영점은 `1/2 +/- 1/4 +/- i`로 임계선 밖에 네 개 있으며,
모든 `T>1`에 대해 오히려

```text
min_sigma |P(sigma+iT)| >= (T^2-1)^2
```

라는 강한 수평 하한을 가집니다.

### 증명과 계산

완성 제타함수 `xi`는 항등적으로 0이 아닌 전해석함수이므로 영점이 고립되어
있습니다. 각 단위 높이 띠의 닫힌 직사각형에는 영점이 유한 개뿐이므로 그
세로좌표들을 피해서 `T_n`을 고를 수 있습니다. 양의 높이에서는 `xi`와
`zeta` 사이의 초등 인자와 감마 인자가 0이 아니며, 닫힌 구간의 연속성으로
양의 최솟값을 얻습니다.

반례 다항식에서는 높이 `+1`인 두 영점까지의 거리가 각각 `T-1` 이상이고,
높이 `-1`인 두 영점까지의 거리가 각각 `T+1` 이상입니다. 네 거리를 곱하면
`(T^2-1)^2`입니다. 생성기의 여섯 높이 격자 계산은 재현용이며, 증명은 이
거리 곱 부등식입니다.

### 한계

실제 `zeta`에 대해 높이나 하한을 계산 가능하게 주지 못했고, 경계의 편각
변화 또는 감김수(winding number)도 인증하지 못했습니다. 반례 다항식에는
제타함수의 오일러 곱이 없습니다. 다음 단계는 구간 연산으로 검증 가능한
중앙 경계 하한과 편각 원리의 영점 개수 증가량을 결합해야 합니다.

## 2. 콜라츠 추측

### 이번에 증명한 정확한 명제

홀수만 보는 가속 사상

```text
T(x)=(3x+1)/2^v2(3x+1)
```

에서 valuation, 즉 `3x+1`을 나누는 2의 지수가 1인 항이 정확히 다섯 개이고
나머지가 임의의 `>=2`인 양의 비자명 주기는 없습니다. 이는 나머지가 모두
정확히 2인 경우만 처리한 TICKET-189보다 엄밀히 강합니다.

### 무한 문제의 유한 환원

가상 주기를 최소 홀수 `m>=3`에서 시작하도록 회전합니다. 첫 valuation은
1이고 마지막은 2 이상입니다. 길이를 `h`, valuation 합을 `A`, 1의 개수를
`k`라 하면

```text
2^A = product_i (3+1/x_i) <= (10/3)^h,
A >= 2h-k,
(6/5)^h <= 2^k.
```

따라서

```text
h <= floor(k log(2)/log(6/5)).
```

`k=5`이면 `h<=19`이고 `h>=20`은 곱 부등식으로 전부 배제됩니다. 남은
`6<=h<=19`에서는 합 `A`도 유한 범위입니다. 최소점 회전을 고정하고 모든
약한 합성(weak composition, 0 이상 정수의 순서 있는 분할)을 열거하면 정확히
29,758개입니다. 유리수 affine 합성을 정확히 수행한 결과 양의 홀수 정수
고정점은 0개입니다.

### 한계

다섯-1 주기 층 전체는 닫혔지만 1이 여섯 개 이상인 주기와 비주기 발산은
열려 있습니다. 개수를 하나씩 늘리는 반복만으로 콜라츠 추측이 증명되지는
않으므로 다음 보조정리는 1의 개수 전체에 균일해야 합니다.

## 3. 강한 골드바흐 추측

### 이번에 증명한 정확한 명제

연속한 홀수 소수 `q<r`의 간격을 `g=r-q`, 짝수 `N=r-1`의 가장 작은
골드바흐 소수 증인을 `W(N)`이라 하면

```text
W(N)>g-2.
```

실제로 모든 소수 `p<=g-2`에 대해

```text
q+1 <= N-p <= r-3
```

이므로 `N-p`는 두 연속 소수 사이에 있어 합성수입니다.

Ford-Green-Konyagin-Maynard-Tao의 장간격 정리

```text
G(X) >> log X log_2 X log_4 X / log_3 X
```

를 이 전달정리에 넣으면 같은 차수의 최소 증인 하한을 가진 무한 짝수 수열을
얻습니다. 여기서 `log_k`는 로그를 `k`번 반복한 함수입니다. 하지만

```text
log_4 N/log_3 N -> 0
```

이므로 이 경로는 TICKET-209의 `c log N log_2 N` 바닥보다 점근적으로
약합니다. 전달정리는 정확하지만 현행 장간격 정리만 가져오는 경로는 현재
결과를 개선하지 못합니다.

### 재현 계산과 한계

생성기는 2,000,000까지 체로 계산하고 마지막 레코드 소수 간격 10개를 뽑아
간격 내부가 전부 합성수인지, 전달 하한 이하 증인이 없는지, 실제 최소
증인이 무엇인지 독립적으로 확인합니다. 모든 유한 표본에는 하한보다 큰
증인이 있으므로 반례는 0개입니다.

이 한계는 “현재 발표된 장간격 하한을 이 전달식에 넣는 방법”에만 적용됩니다.
미래의 더 강한 장간격 정리까지 배제하지 않으며 골드바흐 예외집합도 상계하지
않습니다. 핵심 과제는 여전히 덮개 합동식 바닥 너머의 예외 꼬리를 1 미만으로
만드는 parity-breaking, 즉 소수와 거의소수의 짝홀 구조를 구분하는 추정입니다.

## 4. 쌍둥이 소수 추측

### 이번에 증명한 정확한 명제

모든 정수 `K>=8`에 대해 `X=K!`, `H=K-3`으로 두면
`2<=j<=K-2`인 연속한 아래쪽 후보 `X+j`에는 쌍둥이 소수쌍이 없고

```text
H >= (1/4) log X/log log X
```

입니다.

### 증명

각 `j`에 대해 `j`는 `X+j`를 나누고 `j+2`는 `X+j+2`를 나누며 모두
진약수입니다. 또한

```text
log X <= K log K,
log X >= (K/2) log(K/2),
log log X >= (1/2) log K       (K>=8).
```

따라서 `log X/log log X<=2K`이고 `H=K-3>=K/2`이므로 계수 `1/4`를
얻습니다. 생성기는 `K=8,16,32,64,128,256`에서 모든 나눗셈 인증과 크기
부등식을 다시 검사합니다.

### 한계

이 구간은 여전히 위치 `X`에 비해 매우 짧습니다. 이 크기의 모든 국소
구간에서 쌍둥이 소수가 나온다는 주장은 반박하지만, dyadic 구간
`[X,2X]`의 양의 평균이나 쌍둥이 소수의 무한성과 모순되지 않습니다. 다음
위상 하한은 이런 국소 부재 구간을 명시적으로 허용해야 합니다.
