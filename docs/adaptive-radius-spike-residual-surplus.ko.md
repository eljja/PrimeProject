# TICKET-218: 적응 반지름, 지수 급등, 잔차 모멘트, 아벨 잉여량

## 주장 경계

TICKET-218은 리만 가설, 콜라츠 추측, 강한 골드바흐 추측, 쌍둥이 소수
추측을 **증명하거나 반증하지 않았다**. 이번 티켓은 정확한 부분정리,
축소정리 또는 한계정리 네 개를 증명한다. 네 원래 문제는 모두
`open_not_proven`, 즉 미해결이며 기계 판정의 해결 개수는 0이다.

TICKET-217이 남긴 네 열린 보조정리를 직접 공격했다. 단순히 "정밀도를 더
높인다"고 말하는 대신, 무한 명제로 승격하려면 반드시 넘어야 하는 엄격한
수치 문턱을 문제별로 하나씩 특정했다.

## 1. 리만 가설: 신호가 사라지지 않는 이동 반지름

### 선언한 명제

TICKET-216과 TICKET-217에서 정의한 결함 측도 틀 안에서 높이 `H` 이하의
임계선 밖 영점 대칭쌍 개수를 `C(H)`라 하고 다음 변환을 둔다.

```text
L(r) = integral r^t dC(t),       0 < r < 1.
```

고정된 `tau>0`에 대해 높이에 따라 움직이는 반지름을

```text
r_H = exp(-tau/H)
```

로 선택하면 다음이 성립한다.

```text
r_H^H = exp(-tau),
C(H) <= floor(exp(tau) L(r_H)).
```

`L(r_H)` 대신 엄밀한 상계 `U_H`를 사용해도 같다. 따라서

```text
U_H < exp(-tau)
```

이면 `C(H)=0`을 인증한다. 이 상계가 무한히 커지는 공종 높이열에서
성립하면 모든 유한 높이가 결국 포함되므로 `C` 전체가 0이다. 이미 명시한
`C=0`과 임계선 밖 영점 부재의 동치 아래에서는 RH가 따라온다.

더 일반적으로 `beta_H=-log r_H`라 두면 첫 결함 원자의 관측 신호는

```text
r_H^H = exp(-H beta_H)
```

이다. `H beta_H`가 위로 유계이면 신호에 양의 공통 하한이 있고,
`H beta_H`가 무한대로 가면 신호는 0으로 사라진다.

### 증명과 계산

TICKET-217의 `C(H)r_H^H<=L(r_H)`에 위 항등식을 대입하고 `C(H)`의
정수성을 쓰면 된다. 공종 높이 인증이 모든 유한 높이를 덮는다는 사실이
유한 인증을 전역 결론으로 승격한다. 반지름 일정의 상전이는 지수 항등식에서
즉시 나온다.

생성기는 `tau=1,2`, 높이 `10^2`부터 `10^9`까지를 90자리 Decimal로
검산한다. 이는 구현한 항등식의 재현 검사일 뿐 제타 함수 계산이 아니다.

### 한계정리와 남은 간극

`H(-log r_H)`가 무한대로 가는 일정에서는 높이 `H`의 결함 하나가 만드는
신호가 다시 0으로 간다. 따라서 양의 고정 절대오차 바닥으로는 이 일정을
닫을 수 없다. 새 이동 일정은 정보 손실을 피하지만, 실제 제타 명시적
공식으로부터 필요한 상계를 도출하지는 못했다. 임계선 밖 영점을 발견하지
않았고 새로운 영점 부재 영역도 증명하지 않았다.

## 2. 콜라츠 추측: 지수적 부분몫 급등만이 새 인증을 피한다

### 선언한 명제

다음을 두자.

```text
alpha = log(3/2)/log(4/3)
```

`p_n/q_n`을 `alpha`의 상측 연분수 수렴분수, `q_(n+1)`을 바로 다음
수렴분수의 분모라 하자. 다음 부등식이 성립하면

```text
4(q_n + q_(n+1)) < 3^p_n,
```

TICKET-217의 배율 장벽이 성립한다. 따라서 `p_n/q_n`의 어떤 양의 배수도
단일 산형 콜라츠 주기 `1^k 2^m`의 지수비가 될 수 없다.

이 충분조건으로 배제되지 않는 상측 수렴분수는 반드시

```text
4(q_n + q_(n+1)) >= 3^p_n
```

이라는 지수적 급등 조건을 만족해야 한다.

정확한 유리수 구간 계산으로 연분수 계수 100개를 인증했다. 첫 상측
수렴분수는 TICKET-217의 정확한 밑 차이 비교로, 다음 48개는 새 이웃 분모
부등식으로 배제했다. 다음 미검사 상측 수렴분수는 다음과 같다.

```text
p = 16672027258049147969018986102532625254200541727292
q = 11828991589305104738667316989568711874512497900863
```

그러므로 단일 산형 주기는 다음 범위에 존재하지 않는다.

```text
k < 11828991589305104738667316989568711874512497900863
```

### 증명

연분수 수렴분수의 표준 부등식은 다음과 같다.

```text
|alpha-p_n/q_n| > 1/(q_n(q_n+q_(n+1))).
```

상측 수렴분수에 대해

```text
lambda_n = p_n log(4/3)-q_n log(3/2) > 0
```

이라 하면

```text
lambda_n > log(4/3)/(q_n+q_(n+1)).
```

초등 부등식 `log(1+x)>x/(1+x)`에서 `log(4/3)>1/4`이다. 따라서 선언한
정수 부등식 아래에서는

```text
lambda_n > 3^(-p_n),
exp(lambda_n)-1 > 3^(-p_n)
```

이다. TICKET-217이 이 조건에서 기약 수렴분수의 모든 양의 배수를
배제했으므로 결론이 성립한다. 충분조건의 부정을 취하면 이 방법을 피하는
후보에 필요한 지수 급등 조건을 얻는다.

구현은 불필요하게 거대한 `3^p`를 만들지 않는다. 정수 비트 길이로

```text
4(q+q_next) < 2^p < 3^p
```

를 정확히 인증한다. 두 로그의 양의 atanh 급수에서 얻은 유리수 상·하한으로
연분수 계수 100개를 엄밀히 고정했다.

### 남은 간극

이 로그 비율의 모든 미래 부분몫이 지수적으로 급등하지 않는다는 정리는
아직 없다. 한 번의 매우 큰 다음 분모도 새 충분조건을 피할 수 있다. 더 큰
문제는 단일 산형 word가 다중 valuation run과 비주기 발산을 다루지
않는다는 점이다. 매우 큰 유한 하한을 콜라츠 추측의 증명으로 표현해서는
안 된다.

## 3. 강한 골드바흐 추측: 중심화한 잔차 모멘트 인증

### 선언한 명제

유한 블록의 표현 수를 `A_i>=0`, 임의의 양의 모형을 `M_i>0`이라 하자.
실수 `p>0`에 대해

```text
E_p = sum_i |A_i-M_i|^p,
m   = min_i M_i
```

를 정의한다. 다음이 성립하면 모든 `A_i`가 양수다.

```text
E_p < m^p
```

이 엄격한 문턱은 음이 아닌 실수 벡터 전체에서 날카롭다.

유한 계산에는 다음 양의 정수 모형 형태를 쓴다.

```text
w(n) = round(10^6 n product_{odd prime l | n} (l-1)/(l-2))
```

그리고 정확한 유리수 최소제곱 배율을 적용한다.

```text
M_i = (P/Q) w_i,
P = sum_i A_i w_i,
Q = sum_i w_i^2
```

인증식은 다음 완전 정수 부등식과 동치다.

```text
sum_i |A_i Q-Pw_i|^p < (P min_i w_i)^p
```

`p=8`에서는 시작점 `128, 512, 2048, 8192, 32768`인 다섯 dyadic
블록이 모두 통과했다. `p=4`에서는 다섯 블록 모두 실패했다.

### 증명과 정확한 계산

어떤 `A_j=0`이면 그 좌표의 잔차 하나만으로도

```text
|A_j-M_j|^p = M_j^p >= m^p
```

이므로 엄격한 부등식과 모순이다. `j`가 최소 모형 좌표일 때
`A_j=0`, 나머지 `A_i=M_i`로 두면 등호가 성립한다. 따라서 보편적인
실수 벡터 명제에서 `<`를 `<=`로 바꿀 수 없다. `Q^p`를 곱하면 계산에
사용한 정수형이 나온다.

생성 산출물의 소수 판정표, 표현 수, 반올림 모형 가중치, 잔차, 문턱 비교는
모두 정확한 정수 또는 유리수 연산이다. 표시한 최소 표현 수는 유한 결과의
독립 교차검사로만 사용한다.

### 개선점과 남은 간극

TICKET-217의 비중심 2차 모멘트 지지집합 조건은 다섯 블록에서 모두
실패했다. 양의 산술 모형을 중심으로 잡은 8차 잔차 모멘트는 같은 블록을
모두 인증한다. 이는 정확한 유한 인증이지만 `P/Q`가 완전한 유한 표현 수
벡터로부터 적합되었다. 독립적인 점근 추정은 아니다.

이 경로로 강한 골드바흐를 증명하려면 전수 열거 없이 명시적 cutoff와
다음 형태의 공종 산술 부등식을 증명해야 한다.

```text
sum_{X<=n<2X, n even} |R(n)Q_X-P_X w(n)|^8
  < (P_X min w)^8
```

이 원 방법 또는 분산 추정 입력이 다음 열린 보조정리다. 이번 티켓은 이를
증명하지 않았고 예외집합이 작다는 결과를 예외집합이 비었다는 결론으로
승격하지도 않는다.

## 4. 쌍둥이 소수 추측: 엄격한 아벨 잉여량을 개수로 전이

### 선언한 명제

홀수에서만 지지되는 수열 `0<=a_n<=1`에 대해

```text
F(r) = sum_n a_n r^n,
T(Y) = sum_{n<=Y} a_n
```

를 정의한다. `Y` 뒤의 계수 1인 홀수 기하 꼬리를 `R(r,Y)`라 하면

```text
T(Y) >= F(r)-R(r,Y)
```

가 성립한다.

고정된 `a`에 대해

```text
r_X = 1-1/X,
Y_X = floor((2 log log X+a)X)
```

라 하자. 만약

```text
liminf F(r_X)/(X/log^2 X) >= A
```

이고

```text
A > exp(-a)/2
```

이면

```text
liminf T(Y_X)/(X/log^2 X) >= A-exp(-a)/2 > 0
```

이다. `a_n`을 쌍둥이 소수 시작점의 지시함수로 잡으면 쌍둥이 소수가
무한히 많다는 결론이 따라온다.

### 증명과 날카로움

`F`를 `Y`에서 나눈다. 앞부분은 `r^n<=1`이므로 `T(Y)` 이하이고,
뒷부분은 `a_n<=1`이므로 `R` 이하이다. 정리하면 유한 부등식을 얻는다.
TICKET-217의 결과는

```text
R(r_X,Y_X)/(X/log^2 X) -> exp(-a)/2
```

이다. 하극한을 취하면 정량 결론이 나온다. `X/log^2 X`가 무한대로
가므로 양의 정규화 하계는 비영 항이 무한히 많음을 강제한다.

임계 상수는 이 전이 정보에서 날카롭다. 임의의 고정된 지평선에서 `Y`
이하는 0, 그 뒤 모든 홀수에서는 1인 논리적 수열을 만들면

```text
T(Y)=0, F(r)=R(r,Y)
```

이다. 따라서 임계 계수와 같은 비엄격 하계만으로는 양의 개수를 도출할 수
없다. 이 논리적 수열을 소수 수열이라고 주장하지 않는다.

### 유한 진단과 남은 간극

`a=0`, `X=10^3,10^4,10^5,10^6`에서 적응 지평선까지 쌍둥이 소수를
직접 열거하면 계수 1 꼬리보다 큰 양의 부분 아벨 잉여량이 나온다. 정규화
부분 아벨 값은 약 `1.64`에서 `1.48`로 내려가고 꼬리는 `0.5`로
접근한다. 이 행은 결정론적 double-precision, 즉 배정밀도 진단이며 엄밀한
구간 인증이나 점근 하계가 아니다.

남은 명제는 다음 한 줄로 정리된다.

```text
liminf F_twin(1-1/X)/(X/log^2 X) > 1/2
```

프로젝트는 이를 증명하지 못했다. 특히 이 축소정리는 체 방법의 parity
barrier, 즉 홀짝성 장벽을 넘지 않는다.
