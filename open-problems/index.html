What TICKET-198 actually changed

TICKET-198 did not solve a conjecture. It transfers the rigorous finite-height RH theorem through 3×10^12 into the Xi rectangle language, proves that fixed-run primitive Collatz search still contains explicit infinite admissible families, and proves that the previous Goldbach and Twin Prime targets were respectively insufficient and quantitatively overstrong.

TICKET-198은 난제를 해결하지 않았습니다. 리만 트랙은 Platt–Trudgian의 외부 엄밀 정리를 정수 2≤m≤3×10^12의 Xi 사각형으로 이전했지만 새 영점 검증이나 무한 꼬리 통제를 제공하지 않습니다. 콜라츠 트랙은 TICKET-183의 원시 환원을 입력으로 삼아 고정 run 수에도 scalar-admissible 원시 단어가 무한히 남음을 증명했습니다. 골드바흐 트랙은 collision-free 층만으로는 희소한 충돌 지지층을 닫을 수 없음을, 쌍둥이 소수 트랙은 전 오염 질량 지배가 단순 무한성보다 훨씬 강한 목표임을 확정했습니다.

Exact result / 확립

02 · GLOBAL DESCENTOPEN

Collatz Conjecture 콜라츠 추측

Exact result / 확립
Every fixed run count r≥2 contains an explicit infinite primitive one-third-density family passing both scalar gates.
No-go / 폐기
Primitive normalization plus a fixed run count does not make the remaining search finite.
Next lemma / 다음 보조정리
Obstruct every primitive fixed-run 1/2 word in the admissible density window.

w_(r,k)=1^k2^(2k)(12²)^(r-1)가 각 고정 r에서 무한 원시 단어족을 줍니다. 이들의 affine divisibility와 비주기 궤도는 열려 있습니다.

03 · SIGNED MINOR ARCSOPEN

Strong Goldbach 강한 골드바흐 추측

Exact result / 확립
Collision-free control implies only an O(X/log²X) exceptional-set bound; it does not imply an empty exceptional set.
No-go / 폐기
The infinite diagonal S={2p²} supplies a countermodel to the inference, not a Goldbach counterexample.
Next lemma / 다음 보조정리
Prove an explicit prime-prime margin on every large collision-supported even target.

밀도 1 층의 통제만으로 희소한 예외층을 제거할 수 없습니다. 실제 표현 함수에 대한 충돌 지지층의 점별 하한이 별도로 필요합니다.

Exact result / 확립
A K√X log X twin mass lower bound forces a square-root-scale lower bound for the number of pairs.
